LandCast 2050 Population Dataset
=========================================================================================
ArcGIS Folder:


FILES:

  GRIDS (30 arc-second cells):

  Population -	A subdirectory containing the ArcGIS grid (landcast2050) of the 
		population.  There is also a "Layer" file (landcast2050.lyr) for ArcGIS.

                Each cell value represents the number of people in that 30 arc-second
                cell.

   
  Metadata -	A subdirectory containing the metadata for the LandCast 2050 Dataset.

		

LEGEND FILES:

  landcast2050.lyr  - An ArcGIS layer file for the population grid

  

  OTHER FILES:

  Readme.txt - This file.
  LandCast205.ris - Citation file.
