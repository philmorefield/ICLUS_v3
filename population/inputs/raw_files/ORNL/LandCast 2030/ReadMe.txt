LandCast 2030 Population Dataset
=========================================================================================
ArcGIS Folder:


FILES:

  GRIDS (30 arc-second cells):

  Population -	A subdirectory containing the ArcGIS grid (landcast2030) of the 
		population.  There is also a "Layer" file (landcast2030.lyr) for ArcGIS.

                Each cell value represents the number of people in that 30 arc-second
                cell.

   
  Metadata -	A subdirectory containing the metadata for the LandCast 2030 Dataset.

		

LEGEND FILES:

  landcast2030.lyr  - An ArcGIS layer file for the population grid

  

  OTHER FILES:

  Readme.txt - This file.
  LandCast2030.ris - Citation file.

  
=========================================================================================
