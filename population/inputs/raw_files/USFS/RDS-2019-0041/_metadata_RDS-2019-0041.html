Description:
Abstract:
These data provide observed county-level population and personal income data from 2010 and document the projections of those variables over the 2015-2070 period, in five-year increments, for five Shared Socioeconomic Pathways (SSPs) that are the basis for 2020 Renewable Resources Planning Act (RPA) Assessment socioeconomic scenarios. The SSPs are more fully described in the “RPA socioeconomic scenarios summary” document provided in this publication’s Supplemental Information. These data cover the conterminous United States of America.
Purpose:
These data are a key set of drivers that are used in multiple natural resource analyses done to meet the legislative requirements of the Forest and Rangeland RPA of 1974. Data from several sources were used to create the historical data and provide national scale guidance for the projections. In fulfillment of the Forest and Rangeland Renewable Resources Planning Act of 1974, the USDA Forest Service periodically assesses the condition and trends of the Nation's renewable resources. These data support the development of future scenarios that are the basis for all resource analyses in the Assessment.

Overview_Description:
Entity_and_Attribute_Overview:
DATA

\Data\US county population and income projections by SSP.xlsx: Microsoft Excel 2016 Open XML spreadsheet format file containing projected socioeconomic data used for the 2020 RPA Assessment. This file contains multiple worksheet tabs.

The first tab (“Data documentation”) provides some additional information on the construction of the data.

The second tab (“County names”) provides a list of all counties in the conterminous United States, by state, and the associated FIPS code that identifies each county in the dataset.


There are five tabs focused on population projections (“SSPx POP”), one for each Shared Socioeconomic Pathway (SSP). Each tab contains a title row followed by columns for:

County and State -- county name and its state

FIPS Code -- the FIPS code assigned to the county

2010 (Historical) –- the known population value (in thousands) for the county in 2010

Columns “2015” through “2070” -- the population projections (in thousands) in five-year increments.


There are five tabs focused on personal income per capita projections (“SSPx PICP”), one for each SSP. Each tab contains a title row followed by columns for:

County and State -- county name and its state

FIPS Code -- the FIPS code assigned to the county

2010 (Historical) -- the known personal income per capita (in thousands of 2009 US dollars) for the county in 2010

Columns “2015” through “2070” -- the projected personal income per capita (in thousands of 2009 US dollars) in five-year increments.



SUPPLEMENTAL INFORMATION

\Supplements\RPA socioeconomic scenarios summary.pdf: Portable document format file containing a description of the five Shared Socioeconomic Pathways used in the 2020 RPA Assessment.
